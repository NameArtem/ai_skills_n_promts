# Формат RESOURCES.md

`RESOURCES.md` — курируемый набор доверенных источников по этой теме. Знания для объяснений должны браться отсюда, а не из параметрических догадок. Мудрость приходит из сообществ, перечисленных здесь.

## Структура

```md
# {Тема} Ресурсы

## Знания

- [Книга: «Наука и практика силовой тренировки» Зоцюрски и Кремера](https://example.com)
  Фундаментальный текст о программировании и адаптации. Использовать для: всё, что связано с периодизацией, восстановлением, зонами интенсивности.
- [Статья: «Сколько мне тренироваться?» Грега Наколса (Stronger By Science)](https://example.com)
  Научно-обоснованный обзор ориентиров по объёму. Использовать для: недельные цели по подходам на каждую мышечную группу.

## Мудрость (Сообщества)

- [r/weightroom](https://reddit.com/r/weightroom)
  Сабреддит с высоким качеством сигнала, модерируемый против «бро-науки». Использовать для: критика программ, решение плато.
- Локально: силовой класс по вторникам в {название спортзала}
  Использовать для: коучинг по тягам в реальном времени.
```

## Правила

- **Только высокая надёжность.** Отдавайте предпочтение первичным источникам, признанным экспертам, рецензируемым работам и сообществам со строгой модерацией. Если ресурс — это маркетинг, замаскированный под обучение, исключите его.
- **Аннотируйте каждую запись.** Голая ссылка бесполезна через три месяца. Добавьте одну строку: что она покрывает и когда за ней обращаться.
- **Группируйте по Знания / Мудрость.** Отражает философию в [SKILL.md](./SKILL.md). Нормально, если ресурс появляется только в одной группе.
- **Явно показывайте пробелы.** Если для области, нужной миссии, нет хорошего ресурса, напишите раздел `## Пробелы`, перечисляющий, чего не хватает. Это движет будущий поиск.
- **Безжалостно вычищайте.** Ресурс, оказавшийся неверным, поверхностным или не по миссии, следует удалить, а не закопать. Лучше пять острых источников, чем тридцать посредственных.
- **Фиксируйте предпочтения сообществ.** Если пользователь отказался от вступления в сообщества, отметьте это здесь, чтобы будущие сессии не продолжали их предлагать.
