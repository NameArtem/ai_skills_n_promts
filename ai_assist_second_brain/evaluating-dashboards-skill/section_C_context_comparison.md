# Context & Comparison

Ensure metrics communicate direction, magnitude, and performance relative to expectation.

## Principle

Isolated values invite narrative bias. Comparison anchors interpretation.

---

## Detailed Checks

### 1. Historical Comparison

Each KPI should show:
- At least 30–90 days of trend (where appropriate).
- Period-over-period delta.
- Change magnitude and direction.

Red flags:
- Headline number with no chart.
- Trend shown but no delta.
- Delta shown without baseline context.

---

### 2. Target Anchoring

Verify:
- Clear goal line.
- Expected range.
- Performance vs target explicitly visible.

Red flags:
- Targets only referenced in meetings, not visible.
- KPI slightly below goal but visually indistinguishable.

---

### 3. Normalization

Check:
- Absolute values normalized where necessary.
- Per-user or per-session metrics when scale changes matter.

Red flags:
- Total signups increasing but traffic doubling.
- Revenue increasing but ARPU declining.
- Engagement rising but user base shrinking.

---

## Expanded Example Failures

- “Revenue = $4.2M” displayed large without prior-period context.
- 12% conversion displayed without funnel stage denominator.
- Retention flat line hiding increased acquisition volume.
