# Visual Design Standards

Ensure visual encoding supports cognition and avoids distortion.

## Principle

Clarity > variety. Function > decoration.

---

## Detailed Checks

### 1. Chart Integrity

Flag:
- Pie charts >5 segments.
- 3D bars.
- Dual-axis without labeled units.
- Inconsistent axis scales between similar charts.
- Truncated axes exaggerating changes.

---

### 2. Hierarchy

Check:
- Most important metric top-left.
- Clear grouping.
- Logical flow left-to-right, top-to-bottom.

Red flags:
- Equal-sized KPI tiles.
- Color used decoratively.
- Key metric buried mid-page.

---

### 3. Numeric Formatting

Check:
- No excessive decimals.
- Proper scaling (3.4M not 3,400,000).
- Units consistent.

Red flags:
- 6 decimal places.
- Mixed % and absolute values unlabeled.
