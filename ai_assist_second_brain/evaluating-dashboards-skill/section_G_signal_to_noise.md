# Signal-to-Noise Ratio

Remove non-decision-supporting elements.

## Principle

More data does not equal more clarity.

---

## Detailed Checks

### 1. Redundancy

Identify:
- Duplicate metrics shown in different formats.
- Multiple charts conveying same trend.

---

### 2. Decorative Noise

Flag:
- Heavy backgrounds.
- Logos dominating space.
- Excess gridlines.

---

### 3. Decision Relevance Test

Ask:
- Would removing this metric change the decision?
- Has this metric influenced action in last 90 days?

Red flags:
- “Just in case” charts.
- Secondary metrics occupying prime visual real estate.
