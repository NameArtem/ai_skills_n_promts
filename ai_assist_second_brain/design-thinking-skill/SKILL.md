# Design Thinking

## О методологии

**Design Thinking** — человеко-ориентированный подход к решению проблем и созданию инноваций. Центральная идея: ставить реальные потребности пользователей в центр процесса, итеративно проходя от эмпатии к тестированию прототипов.

### Ключевые характеристики

- **Цель:** инновации и фокус на пользователе.
- **Применение:** создание инновационных продуктов и сервисов, работа с нечёткими или сложными проблемами.
- **Преимущества:** глубокое понимание пользователя, генерация идей, низкий риск провала на рынке, подходит для инноваций.
- **Недостатки:** требует времени на исследование, не всегда подходит для чисто технических задач, сложность измерения результата на ранних стадиях.

## Этапы Design Thinking

Процесс итеративен: допускается возврат на предыдущие этапы.

### 1. Эмпатия (Empathize)

- Изучить пользователей и их потребности: интервью, наблюдение, этнография.
- Составить карту стейкхолдеров, user journey map.
- Вопрос: «Что на самом деле важно для пользователя?»

### 2. Определение проблемы (Define)

- Синтезировать собранные данные в ясную постановку проблемы.
- Сформулировать point-of-view (POV) / проблемное утверждение.
- Создать персоны (user personas).
- Вопрос: «Какую конкретную проблему мы решаем и для кого?»

### 3. Генерация идей (Ideate)

- Мозговой штурм, отложенная критика, метафоры, аналогии.
- Методы: SCAMPER, «как сделать ещё лучше», мозговой штурм с ограничениями.
- Отобрать и скомбинировать лучшие идеи.
- Вопрос: «Какие варианты решений существуют?»

### 4. Прототипирование (Prototype)

- Создать дешёвые и быстрые прототипы: макеты, MVP, скетчи, интерактивные плоттайпы.
- Сделать решения осязаемыми для проверки.
- Вопрос: «Как быстро и дёшево проверить идею руками?»

### 5. Тестирование (Test)

- Протестировать прототипы на реальных пользователях.
- Собрать обратную связь, зафиксировать инсайты.
- Итеративно улучшить решение или вернуться к предыдущим этапам.
- Вопрос: «Что говорят пользователи и что улучшить?»

## Рабочий процесс для AI-ассистента

1. **Эмпатия.** Предложи подготовить список вопросов для интервью, помоги провести «приёмную» роль пользователя (BETTER ничьих: AI может смоделировать ответ типичного персона). Составь карту стейкхолдеров.
2. **Определение.** Помоги сформулировать POV-утверждение и создать персон. Проверь, что проблема реально пользовательская, а не гипотеза продукта.
3. **Идеация.** Устрой мозговой штурм: предложи 20+ разнообразных идей, включая провокационные. Примени SCAMPER. Отбери топ-идеи по критериям.
4. **Прототипирование.** Опиши минимальный прототип, что проверить и как; предложи стек/инструменты для быстрого прототипа.
5. **Тестирование.** Подготовь вопросы для тестирования, помоги интерпретировать ответы и предложи план итераций.

## Чек-лист качества

- [ ] Проведено реальное исследование пользователей (не только предположения).
- [ ] Проблема сформулирована через потребности пользователя (POV).
- [ ] Сгенерировано множество идей без ранней критики.
- [ ] Прототип минимален и дёшев.
- [ ] Результаты тестирования зафиксированы и легли в основу итераций.

## Готовые промпты

- «Действуй по Design Thinking. Этап эмпатии: предложи вопросы для интервью с пользователями продукта [описание продукта].»
- «Сформулируй проблему по методологии Design Thinking для [контекст] и создай 3 персоны пользователей.»
- «Проведи мозговой штурм по методу SCAMPER для идеи [описание идеи].»
- «Опиши минимальный прототип для проверки гипотезы [гипотеза] и план тестирования на пользователях.»
