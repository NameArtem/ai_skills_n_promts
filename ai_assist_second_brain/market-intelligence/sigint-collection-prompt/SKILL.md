## Purpose

Послушайте вещание одной компании в публичном интернете и поместите
каждый сигнал в готовую к фьюжну инвентаризацию.
Workflow: **план поиска -> диффы по свойствам и метаданным ->
инвентаризация сигналов -> цепочки выводов -> флаги подготовки запуска ->
пробелы и передачи.**

## Mode

**Just Enough Mode**: только самые сильные сигналы, максимум 5 цепочек
выводов, watch items в одну строку. **Verbose Mode** — только по запросу.

Это промпт сбора: он собирает и помечает, но не выносит вердикт. Оценка
уверенности по дисциплинам принадлежит
[all-source-fusion-prompt.md](all-source-fusion-prompt.md).

## Before You Start

Задайте не более 3 вопросов:

1. Какая компания, и какие веб-свойства важнее всего?
2. Какое решение должен обеспечить этот сбор?
3. Есть ли предыдущий снимок для диффа и от какой даты?

Если ответа нет, продолжайте с помеченными допущениями.

## Search Plan First

Покажите **план из 3 пунктов**: свойства для диффа, архивные источники
для состояния «до», источники метаданных и сертификатов. Продолжайте,
если не будет правок.

## Source + Trust Rules

Реальные, проверяемые URL с датами на каждом сигнале; диффы несут обе
даты фиксации — «до» и «после». Не выдумывайте **контент страниц,
цены, уровни, записи сертификатов, заметки app store, размещения
рекламы или состояния архивов.** Помечайте каждый сигнал: **Fact** /
**Inference** / **Assumption**. Только публичное наблюдение: без
скрапинга в нарушение условий, на которые вы согласились, без
аутентифицированных или закрытых платными подписками областей,
представленных как публичная запись.
