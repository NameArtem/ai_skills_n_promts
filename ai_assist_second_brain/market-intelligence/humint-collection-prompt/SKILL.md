## Missing Context Rule:
Задайте не более 3 вопросов:
1. «Какая компания и насколько она велика? (30 вакансий значат разное

2. «Какое решение должен обеспечить этот сбор?»
3. «Есть ли специальность или регион, по которым мне следить за
   вакансиями?»

## Instructions:
1. Сначала покажите план поиска из 3 пунктов: источники вакансий,

   pivot, реорганизацию или текучку руководства = примерно 2 квартала
   внутреннего отвлечения = ваше окно.
5. Нормируйте количество вакансий по размеру компании и базовому уровню
   найма, прежде чем называть что-то всплеском; всплеск — это отклонение,
   а не число.

## Pedagogic Notes:
- Чтение досок вакансий как анонсов стратегии учит PM, что численность

- Нормировка всплесков по базовому уровню формирует статистическую

- Обрамление вопросов win/loss вместо выдумывания ответов учит границе

## Purpose

Прочитайте сигналы людей одной компании и поместите каждый сигнал в
готовую к фьюжну инвентаризацию.
Workflow: **план поиска -> вакансии, ходы, настроения, выпускники ->
инвентаризация сигналов -> цепочки выводов -> фрейминг win/loss ->
пробелы и передачи.**

## Mode

**Just Enough Mode**: только самые сильные сигналы, максимум 5 цепочек
выводов, watch items в одну строку. **Verbose Mode** — только по запросу.

Это промпт сбора: он собирает и помечает, но не выносит вердикт. Оценка
уверенности по дисциплинам принадлежит
[all-source-fusion-prompt.md](all-source-fusion-prompt.md).

## Before You Start

Задайте не более 3 вопросов:

1. Какая компания и насколько она велика?
2. Какое решение должен обеспечить этот сбор?
3. Есть ли специальность или регион, по которым следить за вакансиями?

Если ответа нет, продолжайте с помеченными допущениями.

## Search Plan First

Покажите **план из 3 пунктов**: источники вакансий, источники
настроений, источники движений руководства и базовый уровень всплеска.
Продолжайте, если не будет правок.

## Source + Trust Rules

Реальные, проверяемые URL с датами на каждом сигнале. Не выдумывайте
**количество вакансий, должности, названные наймы или уходы, цитаты из
отзывов или результаты интервью.** Никогда не фабрикуйте ответы win/loss —
обрамляйте вопросы и отмечайте пробел. Помечайте каждый сигнал: **Fact** /
**Inference** / **Assumption**. Только сбор по публичным записям: без
претекстинга, без выведывания конфиденциальной информации, без
профилирования частных лиц — публичные профессиональные ходы
руководителей, а не частная жизнь людей.
