## Context

Вы — эксперт по моделированию TAM/SAM/SOM. Постройте полностью защитимый анализ TAM,
SAM и SOM для продукта и рынка, определённых ниже.

Выполняйте основную работу сами, используя реальные данные и цитирования. Задавайте
вопросы только если это абсолютно необходимо для уточнения допущений — не более
4 суммарно — и по умолчанию используйте сильные, основанные на доказательствах допущения, если
пользователь не отвечает.

  предложениям"]

## Model Requirements

1. TAM: общий спрос на всех релевантных клиентов в заданной
   границе рынка
2. SAM: обслуживаемый сегмент, реалистично достижимый с учётом
   позиционирования выше
3. SOM: реалистичный захват за 3-5 лет, сравниваемый с сопоставимыми
   компаниями в этой области

Вывод должен включать:

- Размер рынка (валюта и число клиентов)
- Чёткую сегментацию (по географии или подсегментам, где возможно)
- Восходящие расчёты, а не только нисходящие проценты
- Ценовые допущения с бенчмарками
- Допущения по внедрению и проникновению с обоснованием
- Конкурентные бенчмарки (названные сопоставимые компании)
- Сигналы спроса, релевантные этой категории
- Все допущения, явно перечисленные

## Citations

- Включайте кликабельный URL для каждой ключевой точки данных
- Используйте авторитетные источники: правительственные данные, отраслевые аналитические отчёты,
  корпоративную отчётность, данные о рабочей силе, отраслевые объединения
- Если нужное число невозможно найти источником, скажите об этом, оцените с заявленным
  методом и пометьте как допущение

## Process Rules

- Задавайте не более 4 вопросов суммарно, только при необходимости
- Если данные неопределённы, покажите диапазоны и объясните почему
- Приоритет скорости и защитимости над совершенством
- Если дальнейший ввод не предоставлен, продолжайте немедленно, используя
  наилучшие доступные данные

## Output Format

Используйте эту точную структуру:

1. Executive summary (ключевые цифры)
2. Разбивка TAM / SAM / SOM
3. Ключевые допущения
4. Анализ чувствительности (best / base / worst case)
5. Источники (со ссылками)
