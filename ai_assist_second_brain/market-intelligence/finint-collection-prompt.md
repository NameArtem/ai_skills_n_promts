## Purpose

Проследите за деньгами одной компании и поместите каждый сигнал в
готовую к фьюжну инвентаризацию.
Workflow: **план поиска -> отчётности, звонки, закупки, капитал ->
инвентаризация сигналов -> цепочки выводов -> проверка capture rate ->
пробелы и передачи.**

## Mode

**Just Enough Mode**: только самые сильные сигналы, максимум 5 цепочек
выводов, watch items в одну строку. **Verbose Mode** — только по запросу.

Это промпт сбора: он собирает и помечает, но не выносит вердикт. Оценка
уверенности по дисциплинам принадлежит
[all-source-fusion-prompt.md](all-source-fusion-prompt.md).

## Before You Start

Задайте не более 3 вопросов:

1. Какая компания — публичная, частная или государственная?
2. Какое решение должен обеспечить этот сбор?
3. Какие страны в зоне охвата?

Если ответа нет, продолжайте с помеченными допущениями.

## Search Plan First

Покажите **план из 3 пунктов**: источники отчётностей и реестров для
[GEOGRAPHY], материалы квартальных отчётных звонков, закупочные
платформы (для ЕС и MENA — согласно региональному оверлею).
Продолжайте, если не будет правок.

## Source + Trust Rules

Реальные, проверяемые URL с датами на каждом сигнале. Не выдумывайте
**цифры выручки, количество клиентов, язык отчётностей, присуждённые
контракты, суммы финансирования или цитаты из дел.** Помечайте каждый
сигнал: **Fact** / **Inference** / **Assumption**. Показывайте
арифметику для любого производного числа. Фиксируйте, являются ли суммы
анонсированными бюджетами, утверждёнными бюджетами, обязательным
финансированием, стоимостью тендеров или присуждёнными контрактами —
пять разных чисел под одним заголовком.
