## Purpose

Пройдитесь по публичному следу одной компании и поместите каждый сигнал
в готовую к фьюжну инвентаризацию.
Workflow: **план поиска -> упорядоченный обход источников -> инвентаризация
сигналов -> цепочки выводов -> пробелы и передачи.**

## Mode

**Just Enough Mode**: только самые сильные сигналы, максимум 5 цепочек
выводов, watch items в одну строку. **Verbose Mode** — только по запросу.

Это промпт сбора: он собирает и помечает, но не выносит вердикт. Оценка
уверенности по дисциплинам принадлежит
[all-source-fusion-prompt.md](all-source-fusion-prompt.md).

## Before You Start

Задайте не более 3 вопросов:

1. Какая компания и на каком рынке?
2. Какое решение должен обеспечить этот сбор?
3. Какие сайты отзывов и события реально использует покупатель?

Если ответа нет, продолжайте с помеченными допущениями.

## Search Plan First

Покажите **план из 3 пунктов**: порядок обхода (пресса -> аналитики ->
соцсети -> отзывы -> события -> предсказательные рынки), окно дат и
фильтр шума. Продолжайте, если не будет правок.

## Source + Trust Rules

Реальные, проверяемые URL с датами на каждом сигнале. Не выдумывайте
**цитаты из прессы, оценки аналитиков, количество отзывов, спонсорство
событий или рыночные котировки.** Помечайте каждый сигнал: **Fact** /
**Inference** / **Assumption**. То, что [TARGET] говорит о себе, — это
утверждение, а не факт о рынке. Анонсы — это намерение, пока их не
подтвердит другая дисциплина.
