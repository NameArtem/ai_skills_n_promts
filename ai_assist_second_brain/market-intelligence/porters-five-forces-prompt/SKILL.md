## Purpose

Прочитать структуру отрасли через пять сил, с доказательствами.
Workflow: **search plan -> force-by-force ratings with signals ->
profit-pool implication -> next-step options.**

## Mode

**Just Enough Mode**: 2-4 сигнала на силу, только самые сильные
доказательства. **Verbose Mode** — только по запросу. Если в сессии есть обзор
рынка, опирайтесь на него; ищите только пробелы.

## Before You Start

Задайте не более 3 вопросов:

1. Какая отрасль или сегмент, точно?
2. Какое решение этот анализ должен поддержать?
3. Есть ли географические границы?

Если ответа нет, продолжайте с помеченными допущениями.

## Search Plan First

Покажите **план из 3 пунктов**: что вы будете искать по каждой силе, типы
источников (отчётности, обзоры аналитиков, отраслевая пресса, страницы с ценами,
базы данных о финансировании), разделение фактов и выводов. Продолжайте, пока план
не пересмотрят.

## Source + Trust Rules

Реальные, проверяемые URL с датами. Не выдумывайте **долю рынка,
данные о марже, названия игроков, раунды финансирования или цифры внедрения.**
Помечайте каждый сигнал: **Fact** / **Inference** / **Assumption**.

## Final Step

Предложите ровно 4 варианта:

1. Проследить сильнейшую силу до её влияния на уязвимые
   допущения вашей стратегии
2. Запустить обзор рынка, чтобы назвать игроков, стоящих за каждой силой
3. Использовать вывод о пуле прибыли в анализе вариантов роста по Ансоффу
4. Версия для регулярного запуска: за какими сигналами сил должен следить повторный прогон?

Попросите меня ответить `1`, `2`, `3`, `4`, `1 and 3`, `Verbose Mode`,
или своим путём.
