## Purpose

Обновить анализ PESTEL, сравнивая каждый фактор с предыдущим
запуском и сообщая только о существенных изменениях.
Workflow: **search plan -> factor-by-factor diff -> broken
assumptions -> new entrants to the frame -> next-step options.**

## Mode

Требует предыдущего анализа PESTEL. Если его нет, рекомендуйте сначала запустить
шаблон PESTEL и остановитесь. Just Enough Mode на протяжении всего процесса.

## Before You Start

Задайте не более 2 вопросов:

1. Предыдущий PESTEL для вставки?
2. Есть ли события с тех пор, которые вы уже подозреваете, что они важны?

Если предыдущий анализ предоставлен, продолжайте; помечайте допущения.

## Search Plan First

Покажите **план из 3 пунктов**: какие категории факторов будут активно
искаться в этом цикле, типы источников, разделение фактов и выводов.
Продолжайте, пока план не пересмотрят.

## Source + Trust Rules

Правительственные и регуляторные источники, данные центральных банков и
статистические данные, авторитетные новости, отраслевые объединения, организации по стандартизации. Реальные
URL и даты.
Не выдумывайте **регулирование, статистику, даты или события.**
Метки: **Fact**, **Inference**, **Assumption**.

# PESTEL Delta Report

## 1. Run Header

**Scope (from prior analysis):**
**Prior analysis date:**
**This run date:**

## 2. Factor-by-Factor Delta

Для каждого из P / E / S / T / E / L:

### [Фактор]: [изменился / существенных изменений нет]
- **Что изменилось:** [1-2 пункта, с метками, с цитатами — только если изменился]
- **Затронутое предыдущее допущение:** [какая запись из базового анализа]
- **Интерпретация:** [Inference — последствия для области продукта]

Держите факторы "без существенных изменений" в одну строку каждый.

## 3. Broken Assumptions

- [Записи базового анализа, теперь противоречащие доказательствам — самая
  важная секция запуска; с цитатами]

## 4. New to the Frame

- [Факторы, отсутствовавшие в базовом анализе, которые теперь заслуживают места]

## 5. So What?

- **3** последствия для стратегии или дорожной карты
- **2** фактора, за которыми внимательно следить в следующем цикле
- **3** допущения для проверки

Каждый пункт: метка, уверенность, URL, где уместно.

## Final Step

Предложите ровно 4 варианта:

1. Обновить базовый анализ PESTEL этими изменениями (новая базовая версия)
2. Углубиться в самый значимый изменившийся фактор
3. Проследить влияние разрушившихся допущений на дорожную карту или OKR
4. Задать приоритеты наблюдения на следующий цикл

Попросите меня ответить `1`, `2`, `3`, `4`, `1 and 2`, `Verbose Mode`,
или своим путём.
